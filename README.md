# SVC-addon_AutoMute-Public

株主鯖（Minecraft 1.20.4 / Fabric）で使う **SVC-addon_AutoMute** の配布用リポジトリです。

Simple Voice Chat のアドオン。サーバーに入ったとき・抜けたときに自動でミュートする（SVC 本体は公式版を使います）

- jar は [Releases](https://github.com/Msya-kabunushi/SVC-addon_AutoMute-Public/releases) にあります
- ふだんは株主ランチャーが自動で入れます（手で入れる必要はありません）
- ソースコードは公開していません。再配布・改変はご遠慮ください
